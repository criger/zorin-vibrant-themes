# Repository agent entrypoint

This is the **public product repository** for Zorin Vibrant Themes.

Before edits, read `README.md`, the actual source, and the current `main` branch.

Maintainer-specific rules and the project journal are in the private repository
`criger/projects-ai-commands`, under `projects/zorin-vibrant-themes/`.
Only agents authorized to access that repository should use it. External
contributors can work solely from this public repository.

Preserve original Zorin theming behavior, do not touch users' system files,
and distinguish tested installer behavior from unverified OS compatibility.
The first import was explicitly authorized directly on `main` on 2026-11-20;
this is **not** standing permission for future direct commits.
